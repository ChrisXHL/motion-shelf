# 灵感库 · Motion Shelf

把动效、剪辑、脚本、配乐跟网页参考放在同一个产品里。你可以自己浏览、预览和复制，也可以让当前对话里的 Agent 检索、比较候选，保存参考方案。

## 产品包含哪些库

| 灵感库 | 参考数量 | 主要用途 | 可用范围 |
| --- | ---: | --- | --- |
| 动效灵感库 | 1700 个视频，其中 Vibe Coding 600 个 | 产品宣传、界面演示、图形动效、三维广告、角色动画跟动画短片 | 公开网站和本地插件 |
| 剪辑灵感库 | 240 部成片 | 节奏、转场、声音、叙事、分屏跟时间空间安排 | 本地插件 |
| 脚本灵感库 | 100 条视频参考 | 开头、内容推进跟收束；脚本、标题和简介 Prompt | 本地插件 |
| 音乐灵感库 | 1000 首配乐 | 产品发布、界面演示、节奏卡点跟品牌叙事；查看授权和署名 | 本地插件 |
| 网页灵感 | 713 个案例与免费模板 | 页面、视觉跟交互；查看原站和完整演示 | 本地插件 |

动效数量按当前公开目录计算，其他库按内置目录计算，不包含用户后来上传的本机条目。数量随同步自动更新。免费模板不代表其中所有素材都可免费商用。

## 在线使用

[打开公开网站](https://chrisxhl.github.io/motion-shelf/)

目前公开网站只开放动效灵感库，支持六种类型和细分类、搜索、视频预览、收藏及链接复制。其他四个库、参考方案跟添加内容在本地插件使用，尚未公开部署。

默认显示英语，可在侧栏切换中文，语言选择保存在当前浏览器。分类、操作提示、目录标题跟说明支持中英文，原始作品资料保留。

这是可直接通过 GitHub Pages 托管的静态网站，无需账号或后端。收藏、最近复制和视图偏好只保存在访问者自己的浏览器，不上传、不跨浏览器同步。网站仅展示远程缩略图、播放器和原始视频链接，不保存或重新托管视频；版权归原作者。

## 本地插件

在 Codex 里说「打开动效灵感库」打开面板，再从侧栏切换库；也可以直接让当前 Agent 查找参考、读取依据并保存方案。卡片按用途提供参考 Prompt，复制后在自己的 Agent 中填写主题或已有内容。

本地上传由当前 Agent 跟子 Agent 整理、分类和去重。上传原文、处理记录、私人方案、收藏跟复制记录留在本机。

## 更新跟部署

现有网站由本地同步任务每天凌晨 4 点（UTC+8）检查更新，只发布允许公开的网页文件跟作品清单。README 随发布生成，更新库的内容或功能时也同步维护产品说明。

仓库通过 `main` 分支根目录部署到 GitHub Pages。同步以构建通过并核对线上文件为完成；遇到冲突、数量异常下降或核对失败时停止，保留现有网站。

## 本地预览

`python3 -m http.server 8080 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8080/`。

## 来源与限制

参考来自作者官网、Vimeo、YouTube、Remotion 官方作品展及作者公开 X 帖子及 GitHub 项目中的成品视频。视频链接及制作依据保留在每条记录中。制作方式依据作者或投稿者自述，未逐条复现制作流程或完整观看。平台、网络、地区或发布者设置可能影响预览；无法预览时可打开原视频，Vibe Coding 案例还可查看制作说明。

各库的来源核对、原作研究跟创作建议分开记录。未完整观看、试听或操作的内容，不当作已完成的原作拆解。音乐采用前要核对具体曲目的授权和署名要求。

此仓库只包含公开网页及视频清单，不包含本机个人数据库、研究过程文件或插件服务端。
